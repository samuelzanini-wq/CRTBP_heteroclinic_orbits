ATENÇÃO: Todos os arquivos devem estar na mesma pasta para o programa funcionar. 

Abra o arquivo "parametros.txt" e coloque os parametros desejados nos lugares indicados. Para rodar o programa abra o prompt de comando na pasta onde estão todos os arquivos (comando do tipo: cd C:User\pasta) e rode os seguintes comandos:
1. py -m venv venv
2. venv\Scripts\activate.bat
3. pip install -r requirements.txt
4. py principal.py

Caso você já tenha feito isso, basta ativar o venv (passo 2) e rodar (passo 4)
