Cada pasta contém um programa. Ambos tem a mesma função: calcular e plotar as órbitas 1-heteroclínicas do CRTBP.

Pasta: "orbitas_heteroclinicas_gomez"
Implementação em python do método do GÓMEZ, G. et al. CeMDA 56, 241–242, 1993.

Pasta: "orbitas_heteroclinicas_PSO"
Implementação em python do método do GÓMEZ, G. et al. CeMDA 56, 241–242, 1993. Porém, utilizou-se um outro método chamado "Particle Swarm Optimization" para auxílio.

OBS: O método do PSO demora um pouco mais para o cálculo pois é uma implementação direta autoral da linguagem python. Mas, no geral, ela requer metade do número de integrações do que o método do Gómez de modo que uma implementação nativa do PSO deve rodar mais rápido
